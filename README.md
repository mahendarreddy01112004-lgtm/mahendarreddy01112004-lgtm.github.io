# My Portfolio Website

This is my personal portfolio, live at [mahendarreddy01112004-lgtm.github.io](https://mahendarreddy01112004-lgtm.github.io).

I'm a final year B.Tech CS student looking for data analyst / data engineer roles, and I wanted one place that pulls together all my projects instead of just a list of GitHub links. This repo is that site.

## What's on it

- A short about section
- The tools I actually work with (Python, SQL, R, Excel, Tableau, Power BI, plus the cloud/data engineering basics)
- All five of my portfolio projects, with real numbers pulled from actually running each one, not just descriptions
- Education and certifications
- A contact form and my direct details (email, LinkedIn, GitHub)

## Built with

This site uses the [Paradigm Shift](https://html5up.net/paradigm-shift) template by HTML5 UP (free for personal and commercial use under their license), with all the content, project write-ups, and photo replaced with my own. The contact form runs on [Formspree](https://formspree.io) so messages actually reach my inbox.

## Why I built it this way

I didn't want a generic "Lorem ipsum" template site, so every project section links back to the actual repo (or live dashboard, in Tableau's case) so anyone can go check the real code instead of taking my word for it.
