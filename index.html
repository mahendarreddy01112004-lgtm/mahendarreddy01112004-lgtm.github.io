Projects

Five tools, five real projects. Every number below came from actually running the code, not from a description I wrote first and backfilled later.

IPL Match & Player Performance Dashboard

Tableau  │  relationships  │  calculated fields  │  dashboard filters

17 seasons of real IPL data, connected at match level and ball by ball level using a Tableau relationship instead of a flattening join. Built two calculated fields to answer a question the raw columns couldn't: does winning the toss actually matter.

  • 1,095 matches and 260,920 ball by ball deliveries
  • Toss winners go on to win only 50.6% of matches, barely better than chance
  • Fielding first wins 53.6% of the time versus 45.3% when batting first

UPI Transactions & Fraud Pattern Analytics

SQL  │  SQLite  │  window functions  │  CTEs  │  self-joins

Built a UPI style payments schema from scratch, then wrote layered SQL, business reporting queries plus a five signal fraud model, to flag suspicious accounts using nothing but CTEs, window functions and a composite risk score.

  • 14,300 transactions analyzed across 2,000 synthetic users
  • 22 users flagged by the composite fraud score
  • 4 distinct fraud patterns detected in pure SQL, no ML involved

End-to-End Python ETL Pipeline

Python  │  pandas  │  SQLite  │  logging

A proper extract, transform, load pipeline split into separate modules instead of one script, with real logging and error handling, built to clean messy order data (duplicates, missing values, three different date formats) and load it into SQLite.

  • 2,540 raw rows cleaned down to 2,500
  • 40 exact duplicates removed automatically
  • 87 missing values recalculated instead of dropped

Retail Sales & Customer Insights Dashboard

Excel  │  SUMIFS/COUNTIFS  │  INDEX/MATCH  │  live charts

A multi city retail dashboard built entirely on live formulas, zero hardcoded numbers anywhere in the workbook. A Top 10 customer table using LARGE plus INDEX/MATCH instead of a manual sort, and four charts that update the moment the raw data changes.

  • 1,500 orders across 7 Indian cities
  • Zero formula errors across roughly 4,900 formulas
  • 279 unique customers tracked with a live Top 10 ranking

View repository on GitHub →

Employee Attrition: Statistical Analysis in R

R  │  tidyverse  │  hypothesis testing  │  logistic regression

Took the question a dashboard can't answer well, is this pattern real or just noise, and tested it properly. Chi-square tests, t-tests, and a logistic regression model, plus an honest section on where the model's accuracy number is more misleading than impressive.

  • 1,470 employees analyzed, 16.1% overall attrition rate
  • Working overtime raises the odds of leaving by 4.29 times, the strongest single factor found
  • Every factor tested came back statistically significant at p less than 0.05
